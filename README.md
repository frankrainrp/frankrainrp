A local-first household coordination API for tasks, events, habits and assistant proposals. Member-scoped data and confirm-before-write operations keep model suggestions inside application rules.

Python · SQLite · HTTP APIs · Docker · 24 schema migrations

[Engineering walkthrough](https://github.com/frankrainrp/FamilyOS-Showcase/blob/main/docs/ENGINEERING.md) · [Runnable demo & downloads](https://github.com/frankrainrp/FamilyOS-Showcase/releases/tag/v0.1.0) · [中文](https://github.com/frankrainrp/FamilyOS-Showcase/blob/main/docs/README.zh-CN.md)

### [Bulter](https://github.com/frankrainrp/Bulter)

A local AI learning workspace that turns study material into tasks, calendar entries and linked notes. Includes a configurable Ollama streaming path, document processing and a separate 14-tool MCP server.

TypeScript · Next.js · React · SQLite · IndexedDB · Ollama · MCP

[Technical overview](https://github.com/frankrainrp/Bulter#engineering-walkthrough) · [Windows application & MCP server](https://github.com/frankrainrp/Bulter/releases/tag/v0.1.0) · [中文](https://github.com/frankrainrp/Bulter/blob/master/docs/README.zh-CN.md)
